```swift
import SwiftUI

struct TimerRingView: View {
    let progress: Double   // 0.0 (empty) to 1.0 (full)
    let strokeColor: Color
    let lineWidth: CGFloat = 10
    let size: CGFloat = 160

    var body: some View {
        ZStack {
            // Background track
            Circle()
                .stroke(Color.secondary.opacity(0.2), lineWidth: lineWidth)

            // Progress arc
            Circle()
                .trim(from: 0, to: CGFloat(progress))
                .stroke(strokeColor, style: StrokeStyle(lineWidth: lineWidth, lineCap: .round))
                .rotationEffect(.degrees(-90))  // Start from 12 o'clock
                .animation(.linear(duration: 1), value: progress)
        }
        .frame(width: size, height: size)
    }
}
```

Key specs from UI-SPEC:
- Diameter: 160pt
- Stroke width: 10pt
- Stroke cap: `.round`
- Background track: `.secondary.opacity(0.2)`
- Progress direction: Clockwise from top (`.rotationEffect(.degrees(-90))`)
- Animation: `.linear` on trim change (smooth, not stepping)

The view accepts `strokeColor` as a parameter so PomodoroView can pass:
- `.blue` for work sessions
- `.green` for short/long breaks
