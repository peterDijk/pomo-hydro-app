**6. Internal timer state:**

- `private var endDate: Date?`
- `private var displayTimer: Timer?` (1-second tick for UI refresh)
- `private var autoStartTimer: Timer?`
- `private var activityToken: NSObjectProtocol?` (App Nap prevention — CROSS-04)

**7. Core methods:**

`func start()`:

- Set `state = .working`
- Set `totalSeconds = workDuration * 60`
- Set `endDate = Date().addingTimeInterval(TimeInterval(totalSeconds))` (CRITICAL: deadline-based per Pitfall 2)
- Set `secondsRemaining = totalSeconds`
- Call `beginAppNapPrevention()`
- Call `persistState()`
- Start display timer: `Timer.scheduledTimer(withTimeInterval: 1, repeats: true)` that calls `tick()`

`func pause()`:

- Capture remaining = `max(0, Int(endDate!.timeIntervalSinceNow))`
- Invalidate display timer
- Set `secondsRemaining = remaining`, `endDate = nil`
- Keep state as `.working` (or current)
- Call `persistState()`

`func resume()`:

- Recalculate `endDate = Date().addingTimeInterval(TimeInterval(secondsRemaining))`
- Restart display timer
- Call `persistState()`

`func stop()`:

- Invalidate all timers
- Set `state = .idle`, `secondsRemaining = 0`, `totalSeconds = 0`, `endDate = nil`
- Call `endAppNapPrevention()`
- Call `persistState()`

`func skip()` (during breaks):

- Call `completeCurrentPhase()`

`private func tick()`:

- `guard let endDate else { return }`
- `let remaining = max(0, Int(ceil(endDate.timeIntervalSinceNow)))`
- `secondsRemaining = remaining`
- If `remaining <= 0`: call `completeCurrentPhase()`

`private func completeCurrentPhase()`:

- Invalidate display timer
- If `state == .working`:
  - Increment `sessionsCompleted`
  - Determine next: if `sessionsCompleted % sessionsBeforeLongBreak == 0` → `.longBreak` else → `.shortBreak`
  - If autoStartBreak: start auto-start countdown for break, else set state to `.idle`
- If `state == .shortBreak` or `.longBreak`:
  - If autoStartWork: start auto-start countdown for work, else set state to `.idle`
- Call `persistState()`

`private func startAutoStartCountdown(nextState: PomodoroState)`:

- Set `state = .autoStartCountdown`
- Set `autoStartSecondsRemaining = 5`
- Store `nextState` for use after countdown
- Start `autoStartTimer` (1-second tick, decrement `autoStartSecondsRemaining`)
- When reaches 0: transition to `nextState` and call appropriate start method

`func skipAutoStart()`:

- Invalidate autoStartTimer
- Transition immediately to the pending next state

**8. App Nap prevention** (CROSS-04):

```swift
private func beginAppNapPrevention() {
    guard activityToken == nil else { return }
    activityToken = ProcessInfo.processInfo.beginActivity(
        options: .userInitiatedAllowingIdleSystemSleep,
        reason: "PomoHydro timer is running"
    )
}
private func endAppNapPrevention() {
    if let token = activityToken {
        ProcessInfo.processInfo.endActivity(token)
        activityToken = nil
    }
}
```

**9. Persistence helpers** (CROSS-05):
