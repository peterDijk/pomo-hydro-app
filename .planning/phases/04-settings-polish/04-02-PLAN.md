**PomodoroService.swift — Add recalculateEndDate method:**

Add a public method for mid-session duration recalculation (D-10):

```swift
func recalculateEndDate(oldDuration: Int, newDuration: Int) {
    guard state == .working || state == .shortBreak || state == .longBreak,
          let currentEnd = endDate else { return }
    let delta = TimeInterval((newDuration - oldDuration) * 60)
    endDate = currentEnd.addingTimeInterval(delta)
    totalSeconds = newDuration * 60
    secondsRemaining = max(0, Int(ceil(endDate!.timeIntervalSinceNow)))
    persistState()
}
```

This adjusts the running timer by the difference between old and new duration. If user changes work from 25→30 min mid-session, it adds 5 minutes to the end time.

**PomodoroSettingsTab — Add onChange handlers for duration sliders:**

Add `@Environment(PomodoroService.self) private var pomodoroService` to PomodoroSettingsTab.

For each duration slider (workDuration, shortBreakDuration, longBreakDuration), add `.onChange(of:)` that calls `pomodoroService.recalculateEndDate(oldDuration:newDuration:)`:

```swift
// On the workDuration Slider:
.onChange(of: workDuration) { oldValue, newValue in
    if pomodoroService.state == .working {
        pomodoroService.recalculateEndDate(oldDuration: oldValue, newDuration: newValue)
    }
}

// On the shortBreakDuration Slider:
.onChange(of: shortBreakDuration) { oldValue, newValue in
    if pomodoroService.state == .shortBreak {
        pomodoroService.recalculateEndDate(oldDuration: oldValue, newDuration: newValue)
    }
}

// On the longBreakDuration Slider:
.onChange(of: longBreakDuration) { oldValue, newValue in
    if pomodoroService.state == .longBreak {
        pomodoroService.recalculateEndDate(oldDuration: oldValue, newDuration: newValue)
    }
}
```

Only recalculate if the relevant state is active (don't recalculate break duration while in a work session).
