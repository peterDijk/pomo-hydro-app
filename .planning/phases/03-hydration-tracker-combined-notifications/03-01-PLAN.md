    - `@ObservationIgnored @AppStorage("savedTotalMl") private var savedTotalMl: Int = 0`

    - `@ObservationIgnored @AppStorage("savedHydrationEndTime") private var savedHydrationEndTimeInterval: Double = 0`

    **Private timer state:**
    - `private var reminderEndDate: Date?`
    - `private var reminderTimer: Timer?`
    - `private var notificationService: NotificationService?`

    **Computed properties:**
    - `var progress: Double { guard dailyWaterGoal > 0 else { return 0 }; return min(1.0, Double(glassesConsumed) / Double(dailyWaterGoal)) }`
    - `var goalReached: Bool { glassesConsumed >= dailyWaterGoal }`
    - `var formattedMl: String` — format totalMl with NumberFormatter using `.decimal` grouping (e.g., "1,000")

    **init():**
    - Call `restoreState()` to load persisted glasses + restart reminder if active

    **func restoreState():**
    - Check midnight: compare `savedGlassesDateString` to today string. If different day: reset both counts to 0, update date string (same pattern as PomodoroService.restoreState).
    - If same day: restore `glassesConsumed = savedGlassesConsumed`, `totalMl = savedTotalMl`
    - If `savedHydrationEndTimeInterval > Date().timeIntervalSince1970`: restore reminder timer with remaining time

    **func setNotificationService(_ service: NotificationService):**
    - Store reference. Same pattern as PomodoroService.

    **func logGlass(size: GlassSize? = nil):**
    - Let s = size ?? selectedSize
    - glassesConsumed += 1
    - totalMl += s.rawValue
    - persistState()
    - Restart reminder timer (user just drank, reset countdown to next reminder): call `startReminderTimer()`

    **func startReminders():**
    - Call `startReminderTimer()`

    **func stopReminders():**
    - `reminderTimer?.invalidate(); reminderTimer = nil; reminderEndDate = nil; persistState()`

    **private func startReminderTimer():**
    - Invalidate existing timer
    - Set `reminderEndDate = Date().addingTimeInterval(TimeInterval(reminderInterval * 60))`
    - Start repeating Timer.scheduledTimer(withTimeInterval: 1, repeats: true) that calls tick() on @MainActor (same pattern as PomodoroService)
    - persistState()

    **private func tick():**
    - checkMidnightReset()
    - guard let reminderEndDate else { return }
    - if Date() >= reminderEndDate: fire notification, then restart timer for next interval
    - Fire: `Task { await notificationService?.sendHydrationReminder() }`
    - Then call `startReminderTimer()` to reset for next cycle

    **private func checkMidnightReset() (CROSS-02):**
    - Same pattern as PomodoroService: compare savedGlassesDateString to today, reset if different

    **private func persistState():**
    - savedGlassesConsumed = glassesConsumed
    - savedTotalMl = totalMl
    - savedGlassesDateString = dateString(for: Date())
    - savedHydrationEndTimeInterval = reminderEndDate?.timeIntervalSince1970 ?? 0

    **private func dateString(for date: Date) -> String:**
    - Same as PomodoroService: DateFormatter with "yyyy-MM-dd"

    **var isReminderActive: Bool** — `reminderEndDate != nil`

    **func isHydrationDue(within seconds: TimeInterval) -> Bool:**
    - Returns true if reminderEndDate is within `seconds` from now (used by PomodoroService for merge window D-06)
    - `guard let end = reminderEndDate else { return false }; return end.timeIntervalSinceNow <= seconds`
