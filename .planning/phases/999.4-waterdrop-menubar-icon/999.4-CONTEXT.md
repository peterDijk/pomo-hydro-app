# Phase 999.4: Add Waterdrop to Menubar Icon - Context

**Gathered:** 2026-03-30
**Status:** Ready for planning

<domain>
## Phase Boundary

Replace the current single SF Symbol menu bar icon with a custom-drawn composite icon: a clock with a waterdrop half-overlapping it. This becomes the PomoHydro brand mark in the menu bar.

</domain>

<decisions>
## Implementation Decisions

### Icon Composition
- **D-01:** Waterdrop shown alongside the clock icon, half-overlapping — a composite graphic, not two separate icons side by side
- **D-02:** Always visible in every app state — the waterdrop is the app's unique brand identifier, not a conditional status indicator

### Visual Style
- **D-03:** Custom drawn icon (not SF Symbols) — replace the current `Image(systemName:)` approach with a custom SwiftUI shape or asset-based rendering

### State Reflection
- **D-04:** The clock portion of the composite icon still reflects Pomodoro state (idle, working, break, paused) — the waterdrop remains constant while the clock element visually changes per state

### Agent's Discretion
- How exactly the clock portion visually differentiates states (fill, outline, animation, color) — as long as all four states are distinguishable
- Whether to use SwiftUI `Shape`/`Path` drawing or pre-rendered PDF/SVG assets in the asset catalog
- Exact proportions and overlap amount between clock and waterdrop

</decisions>
